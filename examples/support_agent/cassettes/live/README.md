# Live cassettes

Recordings from **real** models land here, one folder per target or model:

```bash
make record-claude       # needs ANTHROPIC_API_KEY             -> cassettes/live/claude/
make record-mimo         # needs MIMO_API_KEY, MIMO_BASE_URL,   -> cassettes/live/mimo/
                         #       MIMO_MODEL
make record-openrouter   # needs OPENROUTER_API_KEY            -> cassettes/live/openrouter-<model>/
                         #       (MODEL=vendor/model, default anthropic/claude-sonnet-5.5)
```

A drift check against a folder (`make drift-openrouter`, or `record_live.py --against NAME`)
keeps its latest runs in `<folder>/candidates/<model>-<prompt>/`.

They are created only by the repository owner with their own keys. Nothing in this folder is
generated by tooling or by the mock provider: cassettes from the mock provider live one level
up and are labelled `"provider": "mock"`. Once recorded, `tests/test_live_cassettes.py`
replays every cassette here offline, candidates included.

`openrouter-claude-sonnet-5.5/` holds Claude Sonnet 5.5's v1 recordings and three drift checks
against them: Sonnet again (`-v1`), the v2 prompt (`-v2`) and Claude Haiku 5.5 (`haiku-5.5-v1`).
[docs/WALKTHROUGH.md](../../../../docs/WALKTHROUGH.md#with-a-real-model) describes what they show.
