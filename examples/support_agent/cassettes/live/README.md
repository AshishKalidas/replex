# Live cassettes

Recordings from **real** models land here, one folder per provider:

```bash
make record-claude   # needs ANTHROPIC_API_KEY            -> cassettes/live/claude/
make record-mimo     # needs MIMO_API_KEY, MIMO_BASE_URL,  -> cassettes/live/mimo/
                     #       MIMO_MODEL
```

They are created only by the repository owner with their own keys. Nothing in this folder is
generated by tooling or by the mock provider: cassettes from the mock provider live one level
up and are labelled `"provider": "mock"`. Once recorded, `tests/test_live_cassettes.py`
replays them offline like any other cassette.
